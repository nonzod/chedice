    ⚙️ Impostazioni

    Configura separatamente il modello testuale per domande e prompt e il modello vision per le scene. Per ciascuno puoi aggiungere più provider — Ollama o qualsiasi API OpenAI-compatibile (OpenAI, OpenRouter, llama.cpp, vLLM, LM Studio…) — in ordine di priorità: se il primo non risponde viene usato il successivo.

    💬 Assistente testuale

    Usato per domande sulla trascrizione e prompt. Non può usare il servizio vision http://llama:8080. Con un provider remoto la trascrizione viene inviata a quel servizio.

    🎞️ Analisi visiva

    Usata solo per descrivere i fotogrammi; serve un modello multimodale (es. Qwen3-VL sul runtime llama.cpp dedicato http://llama:8080, oppure un modello vision su Ollama o su un'API OpenAI-compatibile). Con un provider remoto i fotogrammi vengono inviati a quel servizio.

    🧹 Pulizia automatica

    Libera spazio sul disco eliminando i job conclusi più vecchi di N giorni (0 = mai). Eliminando solo il file originale la trascrizione resta in archivio, ma non saranno più disponibili campioni voce, analisi scene e ricalcolo parlanti. La pulizia viene eseguita ogni ora.
